# Telemetry UI

Realtime telemetry dashboard for ground-station operators.

> Setup verified by FirstRun at `deaa51b` in `node:20-bookworm`: clone to running in 0m51s.

## Prerequisites

- Node.js 20
- pnpm 9 via Corepack (`corepack enable`)

## Getting started

```bash
git clone https://github.com/orbit-dev/telemetry-ui.git
corepack enable
pnpm install
pnpm dev
pnpm test
```
