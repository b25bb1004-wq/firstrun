HUMBLE Robot Companion

7 expressive states in oat parchment, ink lines & blue/pink accents. 60fps CSS/SVG micro-animations.

State 1

Sleep

Idle state waiting for repo detection. Breathing up/down bobbing + rising ZZZ vector particles.

State 2

Think

Isolation phase executing steps. Rhythmic head tilt, antenna pulse ring & inquisitive upward gaze.

State 3

Walk

Moving across screen to target bounds. Dynamic stride gait with counter-balanced arm swing.

State 4

Point

Showing user where to focus. Outstretched pointing stylus with active radar beacon targeting.

State 5

Talk

Explaining instructions and reasons. Articulated speaking mouth & friendly gesturing hand.

State 6

Celebrate

Verification check passed. Arms raised in victory (\o/), green beacon glow & twinkling confetti sparkles.

State 7

Worried

Break diagnosed or command failed. Hands on cheeks, vibrating caution pink antenna & nervous shiver.
