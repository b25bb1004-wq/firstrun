No warranty

The software and this website are provided as they are, without any warranty. A "verified" result means the setup steps passed on a clean machine at the commit and time shown in the report. It is not a guarantee that they will pass on every machine or at a later commit.

Using the website

Only check public repositories you are allowed to access. Don't use the checker to overload GitHub or our host; requests are rate-limited.

Changes to your repository

HUMBLE never changes a repository by itself. It proposes README and configuration changes as a diff or pull request that a maintainer reviews and chooses to merge.
