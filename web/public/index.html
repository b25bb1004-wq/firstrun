Six agents, one newcomer's afternoon

Deterministic rules handle the common breaks for free. IBM Bob handles what the rules don't recognise. Nothing counts as fixed until it passes on a brand-new machine.

ScoutReads docs next to manifests, lockfiles, compose, CI and the code that reads env vars.
PlannerTurns README prose into ordered steps and flags docs-vs-code conflicts.
RunnerRuns each step in a clean container with databases as sidecars.
DoctorDiagnoses failures: rules first, IBM Bob for the long tail.
VerifierThrows the machine away and replays the repaired guide from zero.
ScribeSmallest README diff, Setup Passport, devcontainer, CI drift guard, PR.
