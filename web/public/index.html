Six agents, one newcomer's afternoon

Deterministic rules handle the common breaks for free. IBM Bob handles what the rules don't recognise. Nothing counts as fixed until it passes on a brand-new machine.

ScoutReads docs next to manifests, lockfiles, compose, CI and the code that reads env vars.
PlannerTurns README prose into ordered steps and flags docs-vs-code conflicts.
RunnerRuns each step in a clean container with databases as sidecars.
DoctorDiagnoses failures: rules first, IBM Bob for the long tail.
VerifierThrows the machine away and replays the repaired guide from zero.
ScribeSmallest README diff, Setup Passport, devcontainer, CI drift guard, PR.
1 · The failureThe exact command and its real output.
2 · The fixWhat changed, and who diagnosed it: a named rule, or IBM Bob and the Bobcoins it cost.
3 · The passThe same step passing, then again in the replay from zero.

Built on IBM Bob

Bob is FirstRun's reasoning engine, its home inside the IDE, and the guide a newcomer talks to.

🩺 Doctor, headless

Bob Shell reads the repo and returns a structured fix. FirstRun refuses anything destructive, then proves the fix in the sandbox.

🚀 FirstRun mode + MCP

Plan, verify and inspect evidence from inside Bob IDE through FirstRun's MCP tools.

🧭 Guide mode

Ships into every verified repo and walks newcomers through steps that are known to work, with the fixes for errors already seen.

Honest limits. The hosted check reads public repositories and runs nothing. Full verification needs Docker and runs locally or in CI (firstrun verify <repo>). Linux containers only. Setups that need real cloud credentials end as "needs a human", never invented values.
