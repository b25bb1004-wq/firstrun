Six agents, one newcomer's afternoon

Deterministic rules handle the common breaks for free. IBM Bob handles what the rules don't recognise. Nothing counts as fixed until it passes on a brand-new machine.

DoctorDiagnoses failures: rules first, IBM Bob for the long tail.

How FirstRun compares

Dev environments, doc linters, and AI assistants each solve adjacent problems. FirstRun is built specifically for the newcomer-facing README: test it on a clean machine, prove what breaks, and fix the guide people read.

Tool / Approach What it does What FirstRun adds
Dev Containers Standardises dev environments by hand-written configuration. FirstRun derives config from a run that passed; doesn't force a new workflow.
Doc Detective Tests documentation code snippets in isolation. FirstRun runs the entire setup as a newcomer, repairs breaks, and replays from zero.
Runme Turns markdown code blocks into runnable interactive notebooks. FirstRun proves the human-facing README natively and repairs what breaks.
DeepWiki / Swimm Explains codebases and architectures with AI. FirstRun proves the setup actually executes and runs, not just explains it.
Copilot setup steps AI suggests setup commands and next steps in chat. FirstRun executes and proves them in a clean sandbox with an evidence record.
Repo2Run (86% Python) Auto-generates container images for bots. FirstRun is language-agnostic and fixes the human-facing README for people.
EnvBench Environment validation benchmark. FirstRun is end-to-end: diagnose, repair, replay from zero, and publish a verified PR.

Honest limits. The hosted check reads public repositories and runs nothing. Full verification needs Docker and runs locally or in CI (firstrun verify <repo>). Linux containers only. Setups that need real cloud credentials end as "needs a human", never invented values.
