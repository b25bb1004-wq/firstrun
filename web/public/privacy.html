Privacy

Last updated 26 September 2026. HUMBLE is a hackathon project run by team HUMBLE. This page says plainly what the website does with data.

No accounts, no tracking

The site has no sign-up, no analytics, no advertising and no tracking cookies. The only thing stored in your browser is your light or dark theme choice, in local storage.

The "Check a README" form

When you check a repository, the name you typed is sent to our server function. It downloads that public repository from GitHub into a temporary folder, reads its docs and manifests, returns the result to you, and deletes the folder. It never runs code from the repository.

To stop abuse, the function keeps your IP address in memory for up to ten minutes to count requests (20 checks per ten minutes). It is not written anywhere. Results for a public repository may be cached by our host for up to fifteen minutes, so the next person checking the same repository gets them faster.

Services we rely on

The site is hosted on Vercel, which keeps standard request logs. The headline font loads from Google Fonts. Repositories are downloaded from GitHub. Each of these services has its own privacy policy.

The HUMBLE command-line tool

When you run HUMBLE on your own machine, it works on your own files and sends nothing to us. If you enable IBM Bob, the parts of a failure log that Bob needs are sent to IBM Bob under your own IBM account and its terms.
